KP NEXUS 2 – Android Buildpaket

Enthalten:
- bestehende Web-App und Intro-Musik
- Android WebView-Projekt
- Android-Aktivität auf Hochformat festgelegt
- mobile CSS-Anpassungen gegen horizontales Scrollen und endlos lange Textzeilen
- GitHub Actions Workflow zum Bauen einer APK

APK bauen:
1. Den Inhalt dieses ZIPs in das GitHub-Repository hochladen (Dateien im Repository ersetzen/ergänzen).
2. GitHub > Actions > Build KP NEXUS 2 APK öffnen.
3. Run workflow starten oder nach Push automatisch laufen lassen.
4. Nach erfolgreichem Lauf im Run unter Artifacts das Artefakt KP-NEXUS-2-APK herunterladen.
5. ZIP entpacken; darin liegt app-debug.apk.

Hinweis: Das ist eine Debug-signierte APK. Wenn eine alte Installation mit anderer Signatur vorhanden ist, muss diese zuerst deinstalliert werden. Die App-Daten lokal können dabei verloren gehen; Cloud-Daten bleiben erhalten, sofern sie in Supabase gespeichert sind.
